# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| latest `main` | :white_check_mark: |
| older releases | :x: |

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Use GitHub's private vulnerability reporting (Repository -> Security ->
"Report a vulnerability") or send a private message to the maintainer.

You will receive an acknowledgement within a few days and a fix timeline
once the report is confirmed. Please include reproduction steps and the
affected component (`packages/nexusagent`, API, dashboard) if possible.
